<h2>🌍 About This Project</h2>

<p>
This project focuses on analyzing country-level data and discovering meaningful
patterns and relationships between different countries based on their economic,
health, demographic, and development-related features.
</p>

<p>
The dataset was carefully cleaned and preprocessed, followed by Exploratory Data
Analysis (EDA). After preparing the data, <strong>Principal Component Analysis (PCA)</strong>
was applied as the main modeling technique to reduce dimensionality and extract
the most important patterns from the dataset.
</p>

</div>

<div style="background:linear-gradient(135deg,#f5faff,#dcecf9); border:1px solid #8bb8df; border-radius:20px; padding:25px; margin:25px 0;">

<h2>🎯 Project Goal</h2>

<p>
The main goal of this project is to analyze country-level features, understand
their relationships, and use PCA to transform the original high-dimensional
feature space into a smaller number of meaningful components.
</p>

<p>
This makes it easier to identify major patterns and visualize similarities
and differences between countries.
</p>

</div>

<div style="background:linear-gradient(135deg,#f8fcff,#d9eaf7); border:1px solid #8bb8df; border-radius:20px; padding:25px; margin:25px 0;">

<h2>🧹 Data Cleaning & Preprocessing</h2>

<p>
The dataset was first inspected and prepared for analysis.
The preprocessing stage included checking data types, identifying and handling
problematic values, preparing numerical features, and transforming the dataset
into a suitable format for further analysis.
</p>

<p>
The final prepared dataset was then used for both EDA and PCA.
</p>

</div>

<div style="background:linear-gradient(135deg,#f4faff,#d4e8f6); border:1px solid #8bb8df; border-radius:20px; padding:25px; margin:25px 0;">

<h2>📊 Exploratory Data Analysis</h2>

<p>
Exploratory Data Analysis was performed to understand the distribution of the
features and investigate relationships between different country-level indicators.
</p>

<p>
Statistical analysis and visualizations were used to identify important patterns,
correlations, and differences across countries.
</p>

</div>

<div style="background:linear-gradient(135deg,#eef7ff,#c8def0); border:1px solid #78a9d0; border-radius:20px; padding:25px; margin:25px 0;">

<h2>🧠 Principal Component Analysis (PCA)</h2>

<p>
After completing the preprocessing and EDA stages, Principal Component Analysis
(PCA) was applied to reduce the dimensionality of the dataset.
</p>

<p>
PCA transforms the original features into a smaller set of principal components
while preserving as much of the important information in the data as possible.
</p>

<p>
The resulting components can then be used to better understand the overall
structure of the dataset and visualize relationships between countries.
</p>

</div>
